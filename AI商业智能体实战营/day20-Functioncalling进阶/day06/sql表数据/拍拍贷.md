### 分析数据  

该项目的主要处理的问题是降低用户的逾期率和逾期金额，所以要先算出逾期率。

#### 逾期率

- 逾期率是指贷款到期的用户里面未还款用户的占比。

- 逾期率 =未还款用户数/贷款到期用户数。

- 未还款用户数：
  - 历史逾期还款期数>0 
- 贷款到期用户数：
  - count('序号')

```sql
#贷款到期用户数和未还款用户数（逾期用户数）
#case when条件判断
select concat(round((t.未还款用户数 / t.贷款到期用户数)*100,2),'%') as 逾期率 from
(
select sum(case when 历史逾期还款期数 > 0 then 1 else 0 end) as 未还款用户数,
count('序号') as 贷款到期用户数 from LC) as t;

#if进行的条件判断
select concat(round(t.未还款用户数 / t.贷款到期用户数 * 100,2),'%') as 逾期率 from(
select count(1) as 贷款到期用户数, 
sum(if(历史逾期还款期数>0,1,0)) as 未还款用户数 from LC) as t;
```

- 经过计算拍拍贷用户逾期率达15%，为降低拍拍贷逾期率，需对逾期用户进行多维度拆解。

#### 多维度拆解       

##### 按照年龄进行数据拆解：

- 对不同年龄段的逾期数据进行分析
- 计算出不同年龄段的总用户数量、未还款用户数、逾期率和逾期期数总计

```sql
#基于年龄划分年龄段
select 
case when 年龄 between 17 and 25  then '17-25'
     when 年龄 between 26 and 35  then '26-35'
     when 年龄 between 36 and 45  then '36-45'
     when 年龄 between 46 and 56  then '46-56'
     else null end
from LC;

#计算出不同年龄段的总用户数量、未还款用户数、逾期率(未还款用户数/贷款到期用户数)和逾期期数总计
select 
(case when 年龄 between 17 and 25  then '17-25'
     when 年龄 between 26 and 35  then '26-35'
     when 年龄 between 36 and 45  then '36-45'
     when 年龄 between 46 and 56  then '46-56'
     else null end) as 年龄段,
     count(序号) as "总用户数",
sum(if(历史逾期还款期数>0,1,0)) as "未还款用户数",
concat(round(sum(if(历史逾期还款期数>0,1,0))/count(序号),2)*100,"%")as "逾期率",
sum(历史逾期还款期数) as "逾期期数总计"
from LC
group by 年龄段
order by 年龄段;
```

结论：

1）产品主要用户年龄分布在17-35岁之间，其中25-35岁用户群体基数最庞大

2）17-25岁的用户的逾期低于平均值，其他年龄段的用户逾期率高与平均值，且随着年龄的增大，逾期率风险也越高；

因此建议将获客目标放在17-25岁的年轻用户群体，适当降低该用户群体的准入门槛，同时对高年龄段的用户在审核和推广方面更加严谨。
